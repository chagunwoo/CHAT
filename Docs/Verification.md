# 검증 기록

검증 날짜: 2026-10-07. 엔진: Unreal Engine 5.5.4 (CL 40574608), Windows 11.

2026-10-08: 입력창의 포커스 상태 글자색을 명시적으로 지정한 후 최종 에디터 빌드를 다시 통과했습니다.

## 빌드

- `CHATEditor Win64 Development`: 성공.
- UHT 헤더 생성 및 모듈 링크: 성공.
- 기존 블루프린트/맵을 엔진 Python commandlet으로 로드·변경·저장: 성공.
- 현재 Source 디렉터리의 CX/CHATX 이름: 없음. CoreRedirects에만 호환을 위한 이전 이름 유지.
- 설치된 MSVC가 UE 5.5 권장 버전보다 최신이라는 엔진 경고는 있으나 빌드는 성공함.

## 실제 네트워크 통합 테스트

UnrealEditor의 서버 모드 프로세스 1개와 게임 클라이언트 프로세스 2개를 localhost UDP로 연결했습니다. 서버 함수를 직접 호출하는 단위 테스트가 아니라 소유 클라이언트의 Server RPC와 실제 복제를 거칩니다.

| 검증 | 승리 시나리오 | 무승부 시나리오 |
| --- | --- | --- |
| 양방향 `/say` 채팅 수신 | 성공 | 성공 |
| `abc`, `112`, `012`, `12` 입력 후 0/3 유지 | 성공 | 성공 |
| 이전 라운드 ID의 정답 요청 거절 | 성공 | 성공 |
| 플레이어 A의 시도가 B의 횟수에 영향 없음 | 성공 | 성공 |
| A의 3회 소진 후 4번째 정답 `386` 거절 | 성공 | 성공 |
| 올바른 승리/무승부 공지와 최종 횟수 수신 | 양쪽 성공 | 양쪽 성공 |
| 다음 라운드에서 두 플레이어 모두 0/3 | 양쪽 성공 | 양쪽 성공 |

UI를 렌더링한 클라이언트에서도 한국어 안내, 두 플레이어 점수, 판정 기록, 결과 공지, 재시작 카운트다운을 확인했습니다. 초기 포커스 오류는 실제 입력창으로 포커스를 지정하도록 수정했습니다.

## 재현

```powershell
.\Scripts\Test-Network.ps1 -Scenario Win
.\Scripts\Test-Network.ps1 -Scenario Draw
```

로그는 `Saved/NetworkTests/<시나리오-시각>`에 생성됩니다. 각 클라이언트 로그의 `CHAT_SMOKE_PASS`가 성공 기준이며 `CHAT_SMOKE_FAIL` 또는 시간 초과 시 스크립트가 실패합니다. 프로세스 정리는 이 스크립트가 시작한 PID에만 적용합니다.

## 검증 범위

에디터 모듈 빌드와 로컬 멀티플레이를 검증했습니다. Shipping 패키징, 다른 PC 사이의 LAN/WAN 연결, 제출용 MP4 녹화는 수행하지 않았습니다.
